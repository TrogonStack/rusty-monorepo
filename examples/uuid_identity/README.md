# Generated UUID identities

This workspace example binds Rust recipes generated by
[`protoc-gen-trogon`](https://github.com/TrogonStack/protoc-gen/tree/main/cmd/protoc-gen-trogon)
to an object-ID newtype. The generated source is checked in, so Cargo builds
need neither a protobuf compiler nor a code generator. The example runtime is
`#![no_std]` and uses neither an allocator nor random or time generation.

```rust
use uuid_identity_example::{generated::{SkuIdentityVersionV1, SkuIdentityVersionV1Input}, SkuId};

let id = SkuId::from(SkuIdentityVersionV1::uuid5(SkuIdentityVersionV1Input {
    warehouse_id: "warehouse-17",
    sku_code: "ABC-123",
}));
assert_eq!(id.to_string(), "sku_1724f7cd-15b8-5e76-ba00-70d188c9b209");
# Ok::<(), trogon_object_id::ParseError>(())
```

The ID declaration is a single newtype with a statically selected recipe:

```rust
use uuid_identity_example::generated;

#[derive(trogon_object_id::ObjectId)]
#[object_id(prefix = "sku", template = generated::SkuIdentityVersionV1)]
#[repr(transparent)]
struct SkuId(trogon_object_id::Uuid);
```

The generated marker's namespace is fixed during generation. Templates
containing fields hash borrowed input bytes at runtime. Static templates embed
a final UUID constant. The resulting object ID stores a 16-byte UUID;
formatting its prefixed text form with `to_string()` allocates a string.

Run `cargo test -p uuid_identity_example` to verify the generated recipes and
their object-ID integration against independent UUIDv5 vectors.

## Regenerate the recipes

Install the plugin version used for this example:

```sh
go install github.com/TrogonStack/protoc-gen/cmd/protoc-gen-trogon@1bc3eb997af84f04106e6031f5232335c9cb6d1b
```

From the repository root, run:

```sh
cd examples/uuid_identity
protoc -I proto \
  --plugin=protoc-gen-trogon="$(go env GOPATH)/bin/protoc-gen-trogon" \
  --trogon_out=src \
  --trogon_opt=language=rust,features=uuid \
  identity.proto
rustfmt --edition 2021 src/identity.uuid.rs
```

The input is [`proto/identity.proto`](proto/identity.proto). The option schemas
under `proto/trogon/uuid/v1` provide its public Trogon UUID imports. The plugin
writes [`src/identity.uuid.rs`](src/identity.uuid.rs), included by the
`generated` module. Recipe marker names come from the protobuf enum value
names; changing those names, namespace text or template bytes changes identity.
Regenerate and run the tests together when modifying recipes.
