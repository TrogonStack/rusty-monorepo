# trogon_object_id_derive

Derive macros for [`trogon_object_id`](../trogon_object_id/README.md).
Enable that crate's `macros` feature to use `ObjectId` for identifier structs
and enums. `ObjectIdDomain` supports the advanced domain-marker API.
Applications depend on the facade rather than importing this crate directly.
